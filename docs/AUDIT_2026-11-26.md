# Portfolio audit — 26 November 2026

Scope: current working tree, local development database shape, public/admin data paths, authentication, CSP, metrics, CI, and migration workflow. This is a code and configuration review, not a penetration test or production-data verification. `npm audit` returned zero advisories for the current lockfile on this date. `npm test` (72 tests), typecheck, lint, and `npm run build` passed after removing the skill seed; the build emitted MongoDB topology-closed cache revalidation warnings despite exit code 0.

## Current controls worth retaining

- Admin mutations and full admin reads call `requireAdmin`, which checks a signed token against an active MongoDB session. One configured owner identity and passkey sign-in are used.
- Inputs have runtime allowlists; contact requests have bounded JSON bodies, sender/global rate limits, plain-text email, and generic failure responses.
- The per-request CSP uses nonces and has no `unsafe-inline` in production; image optimizer settings reject SVG optimization and local IP fetching.
- The dependency advisory scan reported zero current advisories. Repeat it at release time; an advisory scan does not replace the code and deployment review.
